# Core Banking Mini Project

## Project Overview

This project is a **Core Banking Mini Project** developed to simulate real-world banking operations using **Oracle SQL** and **PL/SQL**.

The objective of this project is to demonstrate how a banking system manages customer accounts, transactions, balances, and other day-to-day banking activities
through a relational database. 
It focuses on implementing database design, SQL queries, and PL/SQL programming to automate business processes and maintain data integrity.

The project is designed as a hands-on learning initiative to strengthen database development skills while 
following concepts commonly used in enterprise Core Banking Systems.

---

## Objectives

- Design a relational database for a banking system.
- Store customer, account, and transaction information.
- Implement banking business logic using PL/SQL.
- Perform CRUD (Create, Read, Update, Delete) operations.
- Generate meaningful reports using SQL queries.
- Demonstrate the use of stored procedures, functions, packages, and triggers.
